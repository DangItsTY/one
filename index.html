one

: the one stop solution for all the things

My cumulative life management tools thus far come together in one centralized solution hub, like a toolbox that I can just pick up and use for the right job.

oneschema

: all the things are just notes

Notes are simple JSON objects with a JSON Schema for some structure, but still keeps data as freeforming.

onelist

: it's just another todo list, but one that you actually didn't know you needed

A todo list powered by AI which computes only the most urgent and important tasks according to you.

textboard

: a list that goes sideways, and that's it

For whatever reason, you need to see a list of things horizontally because vertical just ain't cutting it and whiteboards ain't doing it b/c you like typing.

manylists

: you've got an itch to just see multiple lists at once

When looking at one list is too boring and you need to juxtapose a bunch of lists at once to feel like you're in a matrix.

noted

: the first tool that started it all, because it actually worked

Let this tool KISS you by jotting down a something and then just move on with life.

export

: data export because that's just how it do

On a technical level, one is designed to be as safe and private as possible so you'll always own your data and never pings back to the server or interwebs.

import

: data import because you're cool and smart and just want to load another set of data

You can always copy your own data b/c you own it, and you can also import other data like you would a memory card back in the console days.
